# Experiment 02: @cursor on GitHub PRs
Once GitHub is connected, try these flows:
1. Open a pull request that changes `experiments/01-hello-github/hello.py`
2. Comment on the PR: `@cursor fix the greeting to include today's date`
3. Comment on an issue: `@cursor add a new experiment under experiments/03-your-idea/`
Cursor needs the GitHub App installed on the repo with read/write access.
